# Trending YouTube Video Analysis

## Foundations of Computer Science Project (2025–2026)

This project analyzes trending YouTube videos collected from multiple countries using Python and the Pandas data analysis library.

The objective is to explore patterns in trending content by examining video popularity, publishing behavior, categories, tags, audience engagement, and country-specific trends.

---

## Project Objectives

The analysis focuses on:

- Identifying videos without tags
- Measuring channel popularity through total views
- Cleaning the dataset by removing unavailable videos
- Computing like-to-dislike ratios
- Studying publishing time patterns
- Analyzing the most common tags
- Identifying the most viewed videos by country and date
- Mapping video categories across countries
- Detecting videos with unassignable categories

---

## Dataset

The dataset contains trending YouTube videos from several countries, including:

- Canada (CA)
- Germany (DE)
- France (FR)
- Great Britain (GB)
- India (IN)
- Japan (JP)
- South Korea (KR)
- Mexico (MX)
- Russia (RU)
- United States (US)

Each record includes information such as:

- Video title
- Channel name
- Views
- Likes and dislikes
- Tags
- Publish date
- Category ID
- Country

## Conclusion

The analysis revealed important patterns in YouTube trending content across different countries. Entertainment, music, comedy, and news-related videos were among the most frequently trending categories. The project also demonstrated how data cleaning, aggregation, and exploratory data analysis techniques can be applied to large real-world datasets to uncover meaningful insights.
