# Trending YouTube Analysis

Foundations of Computer Science Project (2025-2026)

This project analyzes trending YouTube videos from multiple countries using Python and Pandas.

The project includes:

- Data cleaning
- Data aggregation
- Tag analysis
- Publish time analysis
- Category analysis
- Views, likes, and dislikes statistics
